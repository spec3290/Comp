# 코드 리뷰: 이벤터스·코드포코리아 수집 소스 추가

- 날짜: 2026-11-11
- 브랜치: `feature/40_eventus-code4korea` (이슈 #40)
- 기능: F2-1(대회 수집), 관련 F3-1(분야 소스 태그)
- 결정: Q-25(이벤터스), Q-26(코드포코리아), Q-27(온오프믹스 제외) 신설, Q-1 갱신 — 모두 2026-11-11 사용자 결정

## 배경
사용자가 코드포코리아·이벤터스·온오프믹스를 소스로 추가해 달라고 요청했다. 사이트를 직접 확인한 결과:
- **이벤터스**: `/search?query=` 첫 페이지(12건)만 서버가 결과를 `searchDataRaw`로 실어 준다. 유형·분야 필터와 다음 페이지가 쓰는 검색 API는 직접 호출하면 401이라 쓰지 않았다.
- **코드포코리아**: 사용자가 지정한 code4korea.org는 '개발자 행사 목록' 정적 페이지이고 데이터는 공개 Google 시트다. 페이지에 박힌 API 키 대신 공개 CSV 내보내기를 쓴다.
- **온오프믹스**: 크롤러 UA로는 robots.txt까지 HTTP 500, 일반 UA에만 응답한다. UA 위장으로 우회하지 않고 제외했다(Q-27).

### 권장
1. **소스 간 중복이 병합되지 않는다** — 같은 대회가 이벤터스와 코드포코리아에 함께 올라오면(예: '제5회 2026 AI 스마트워크톤'), 코드포코리아는 주최가 비어 있고 마감일도 접수 마감(11-15)이 아니라 행사일(11-20)이라 merge_key(제목+주최+마감일, F2-2)가 달라 두 건으로 보인다. Q-2(정규화 수준, 열림)를 정할 때 참가 URL 동일성이나 주최 없는 소스의 병합 규칙을 같이 검토한다.
2. **코드포코리아 주최가 빈 문자열** — 시트에 주최 열이 없다(Q-26). 프론트에서 주최가 비면 표시를 숨기는 처리가 필요하다.
3. **이벤터스는 검색어 첫 페이지만 본다** — 검색어 12개 × 12건이라 IT 대회가 많아지면 일부를 놓친다. 페이지 구조(`searchDataRaw` 한 줄)가 바뀌면 `ValueError`로 그 소스만 실패하고 다른 소스와 기존 데이터는 유지된다. 다만 Q-21에 따라 정기 수집 실행이 실패로 표시된다.
4. **요청 수 증가** — 이벤터스는 매 수집마다 검색 12회 + 외부 접수 대회의 상세 페이지 요청이 생긴다(요청 간 1초 지연, 2026-11-11 실측 4건 수집).
5. **`pyproject.toml` 미커밋 변경**과 `build/` — 작업 전부터 있던 변경이라 커밋하지 않았다.

### 확인한 것
- 명세: F2-1 수용 기준(저장 필드, 공식 참가 URL만, 실패 시 기존 데이터 유지·소스 격리, 포스터 미수집)을 두 소스에 적용. features.md 진행 줄에 소스와 Q-번호 추가, F3-1 소스 태그 설명 갱신. F2-1 상태는 `wip` 유지(다른 항목 진행 중).
- 결정: 열린 Q-항목 추측 없음. 범위·필터·날짜 해석·참가 URL 규칙을 Q-25~27에 적고 사용자 답을 받은 뒤 구현. 데이터 모델·API 변경 없음(ADR-0004/0005 그대로).
- 아키텍처: 두 수집기 모두 `ContestSource` Protocol 구현체로 `crawlers/`에 두고 `collect.py`에 등록. 정규화·분류는 기존 service/rules가 그대로 한다. 대회 형식 단어 판정(`looks_like_contest`)은 두 수집기가 같이 쓰므로 `crawlers/base.py`로 올렸다. AC-1~3 유지, `noqa`·`type: ignore` 없음.
- 정확성: 이벤터스 UTC 시각은 `astimezone(KST)`로 날짜를 낸다(테스트: 2026-10-31T15:00Z → 11-01). naive datetime 없음. 코드포코리아는 시트 문자열에서 날짜만 읽는다. 상세 페이지 실패는 그 대회만 건너뛰고(테스트), 검색 페이지·시트 HTTP 오류와 구조 변경은 예외로 올려 서비스가 기존 데이터를 유지한다.
- 보안: 비밀 값 없음(공개 시트 ID만 상수). 사이트가 봇을 막는 경우 우회하지 않음. robots.txt 확인(event-us `/search`·행사 페이지 허용, docs.google.com `/spreadsheet` 허용). 참가 URL은 `html.unescape`만 하고 `http(s)://` 링크만 받는다.
- 주석: 새 모듈·클래스·함수·테스트 모두 한 줄 docstring, 근거가 필요한 곳(Q-14·Q-20·Q-25·Q-26)만 줄을 늘림.
